# Digitale Selbstlernkurse

Interaktive Selbstlernkurse und Übungen für **Mathematik**, **Physik** und **Naturwissenschaften** an der Fachoberschule und Berufsoberschule (FOS/BOS) in Bayern.

Die Kurse laufen direkt im Browser, auf dem Computer, dem Tablet und dem Handy. Sie brauchen keine Installation und keine Anmeldung. Der Lernfortschritt bleibt nur im Browser des jeweiligen Geräts gespeichert. Es werden keine Daten an einen Server übertragen.

**Zur Website:** https://onlinemathandphysics.github.io/digitale-selbstlernkurse/

## Aufbau des Repositorys

```
index.html                          Startseite
impressum.html                      Impressum und Datenschutz
favicon.svg, favicon.ico            Symbol im Browser-Tab
apple-touch-icon.png                Symbol auf dem Homescreen (iPhone, iPad)
mathematik/
  additum-fosbos-12t/
    index.html                      Übersicht Additum 12T
    goniometrische-gleichungen.html
    quiz-allgemeine-sinusfunktion.html
naturwissenschaften/
  fosbos-12-nichttechnik/
    index.html                      Übersicht Naturwissenschaften 12 Nichttechnik
    kraefte-und-ihre-wirkungen.html
```

Jede Kursdatei ist in sich abgeschlossen: Schriften, Formelsatz und Grafiken sind eingebettet. Die Kurse funktionieren deshalb auch offline, wenn man die HTML-Datei herunterlädt und im Browser öffnet.
